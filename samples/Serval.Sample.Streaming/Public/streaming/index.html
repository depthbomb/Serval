Streaming with Serval

Try server-sent events and WebSockets using the browser's built-in clients.

Server-sent events

The server sends ten numbered tick events, one every 250 ms, with heartbeat comments. Each connection ends after three events. EventSource waits one second, then reconnects with Last-Event-ID to pick up where it left off.

Stopped

    Starting again creates a new sequence. The client closes after event 10. A reconnect with Last-Event-ID: 10 gets HTTP 204, which also stops automatic reconnects.

    WebSocket echo

    Connect to /socket, then send a message as text or UTF-8 binary data. The server echoes the same bytes and message type, including fragmented messages.

    Disconnected

      The server limits each message to 64 KiB and disconnects idle clients after two minutes. This page keeps the latest 100 log entries.

      Try it from a terminal

      Run these from another terminal while the sample is running on its default port:

      curl.exe -N http://localhost:8105/events
curl.exe -N -H "Last-Event-ID: 7" http://localhost:8105/events
curl.exe -N http://localhost:8105/records

      Use curl on macOS or Linux. The /records endpoint streams five newline-delimited JSON records. Use a WebSocket client with ws://localhost:8105/socket. Adjust the port if you started the sample with -- --port.
