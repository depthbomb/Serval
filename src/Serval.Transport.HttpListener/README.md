# Serval.Transport.HttpListener

Serve HTTP requests and WebSocket connections through `System.Net.HttpListener`. Most Serval samples use this transport.

Follow the [quick start](https://github.com/depthbomb/serval/blob/master/README.md#try-it-out) to register it with
`AddHttpListener()`.
The [transports sample](https://github.com/depthbomb/serval/tree/master/samples/Serval.Sample.Transports) shows further
configuration.
