# Serval.Authentication

Cookie and bearer authentication for Serval, with authorization policies, password hashing, and CSRF helpers.

The [cookie sample](https://github.com/depthbomb/serval/tree/master/samples/Serval.Sample.CookieAuth) covers sessions
and sign-in.
The [bearer sample](https://github.com/depthbomb/serval/tree/master/samples/Serval.Sample.BearerAuth) shows tokens and
authorization policies.
For the initial app setup, see the [quick start](https://github.com/depthbomb/serval/blob/master/README.md#try-it-out).
