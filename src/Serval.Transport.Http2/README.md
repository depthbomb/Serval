# Serval.Transport.Http2

An experimental HTTP/2 transport for Serval, with TLS and cleartext support over TCP.

The [transports sample](https://github.com/depthbomb/serval/tree/master/samples/Serval.Sample.Transports) shows setup; run it with `-- --http2`.
See the [quick start](https://github.com/depthbomb/serval/blob/master/README.md#try-it-out) for the basic Serval app structure.
