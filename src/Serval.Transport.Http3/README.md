# Serval.Transport.Http3

An experimental HTTP/3 transport for Serval using QUIC. It requires host QUIC support and a TLS certificate.

The [transports sample](https://github.com/depthbomb/serval/tree/master/samples/Serval.Sample.Transports) shows setup; run it with `-- --http3`.
See the [quick start](https://github.com/depthbomb/serval/blob/master/README.md#try-it-out) for the basic Serval app structure.
