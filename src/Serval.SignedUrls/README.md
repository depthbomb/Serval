# Serval.SignedUrls

Create signed links with optional expiration, then validate them in a controller or middleware.
Route and query values are signed but remain readable.

See the [setup example](https://github.com/depthbomb/serval/blob/master/README.md#signed-urls) or run the
[signed URL sample](https://github.com/depthbomb/serval/tree/master/samples/Serval.Sample.SignedUrls).
