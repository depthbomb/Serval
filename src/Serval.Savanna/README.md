# Serval.Savanna

Savanna compiles `.svn` templates into typed C# during the build. Templates support HTML escaping, layouts,
includes, and reusable components.

The [Savanna sample](https://github.com/depthbomb/serval/tree/master/samples/Serval.Sample.Savanna) shows template
syntax and project setup.
See the [main README](https://github.com/depthbomb/serval/blob/master/README.md) for Serval setup and the Rider plugin.
