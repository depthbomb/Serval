# Serval.Vite

Generate C# asset references from Vite's `manifest.json` during the build, with development URLs for Vite's
hot module replacement (HMR).

The [Vite sample](https://github.com/depthbomb/serval/tree/master/samples/Serval.Sample.Vite) shows manifest
configuration, asset rendering,
and development server setup. See
the [sample instructions](https://github.com/depthbomb/serval/blob/master/README.md#samples) to run it.
